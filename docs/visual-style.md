# Visual continuity

The course’s pale blue canvas, white rounded panels, navy text, blue actions, orange emphasis, astronaut mascot, hero, four tabs, and large readable typography remain consistent.

Thread cards distinguish a primary coordinator with an orange left edge and child reviewers with blue. The selected pair appears explicitly in the details, conversation, and both comparison snapshots. Cached histories are rendered separately with the same sanitized rich-text and code-coloring helpers used in earlier lessons.

All code surfaces use highlight.js: method/parameter examples, details and event JSON, request traces, comparison answers, live messages, workflow step code, setup, and the standalone example. Keyboard tabs, explicit labels, focus styles, status announcements, text-size preference, and internal code/diagram scrolling support desktop and mobile.
